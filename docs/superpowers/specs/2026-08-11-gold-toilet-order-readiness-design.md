# 황금변기 주문 준비 화면 개선 설계

## 목표

시가 수신 전에도 확정 가능한 매수 비중 금액을 보여주고, 시가 수신 후에는 일반 매수와 LOC 주문에 필요한 가격과 수량을 각각 명확히 표시한다. Yahoo 자동 시가가 지연되더라도 뉴욕 정규장 시작 후 사용자가 시가를 직접 입력해 주문을 준비할 수 있어야 한다.

## 표시 구조

### 시가 없이 표시하는 정보

- 계좌 원금과 저장된 매수 비중이 있으면 `매수 비중 금액`을 상단에 즉시 표시한다.
- 계산식은 `투자원금 × 매수 비중 ÷ 100`이며 센트 단위로 반올림한다.
- 이 값은 백엔드에서 계산해 응답하므로 프론트엔드가 금융 계산식을 중복 구현하지 않는다.

### 시가 확정 후 표시하는 주문 정보

- 매수가
- 매수가 주문 수량
- LOC 매수가
- LOC 주문 수량

두 주문 수량은 현재 전략 규칙을 유지해 두 가격 중 낮은 가격으로 매수 비중 금액을 나눈 정수 수량이며, 두 카드에 같은 값으로 표시한다. 가격과 수량은 각각 복사할 수 있다.

## 직접 시가 입력 규칙

- 뉴욕 정규장 시작 전에는 직접 입력을 잠근다.
- 정규장 시작 이후에는 Yahoo 자동 시가 수신 여부와 관계없이 직접 입력을 허용한다.
- 직접 입력값이 있으면 계산에는 직접 입력값을 우선 적용한다.
- 서버의 Yahoo 자동 시가 수집은 직접 입력 여부와 관계없이 계속 진행한다.
- 직접 입력 후에는 `자동 시가로 되돌리기` 버튼을 표시한다.
- 버튼을 누르면 직접 입력값만 삭제한다. 자동 시가가 있으면 즉시 자동 시가를 적용하고, 없으면 자동 시가 대기 상태로 돌아간다.

## 백엔드 변경

- 주문표 응답에 시가와 무관한 `allocation_amount`를 추가한다.
- 계좌와 주문표가 있으면 시가가 없어도 `allocation_amount`를 반환한다.
- 유효 시가는 직접 입력값을 먼저 선택하고, 없을 때 Yahoo 자동 시가를 선택한다.
- 직접 입력 가능 여부는 `America/New_York` 기준 주문일 09:30 이후인지 서버에서 판단해 응답한다.
- 자동 시가 수집기는 기존처럼 미수신 주문표를 계속 조회하고 최초 유효값을 저장한다.

## 프론트엔드 변경

- 시가 상태 영역 위에 매수 비중 금액 카드를 표시한다.
- 주문 결과를 일반 매수 가격·수량과 LOC 가격·수량의 네 카드로 표시한다.
- 서버가 반환한 직접 입력 가능 여부로 입력 필드와 버튼을 제어한다.
- 직접 입력값이 적용된 상태에서도 자동 시가 수신 여부를 별도로 보여준다.

## 오류 및 상태 처리

- 계좌 또는 주문표가 없으면 매수 비중 금액은 `-`로 표시한다.
- 직접 입력값이 적용되었지만 자동 시가가 없으면 계산은 정상 표시하고 자동 시가는 `조회 중`으로 표시한다.
- 직접 입력 해제 후 자동 시가가 없으면 주문 계산을 숨기고 대기 상태를 표시한다.
- 잘못된 직접 입력값은 기존의 양수 검증을 유지한다.

## 테스트

- 시가 없이 매수 비중 금액이 반환되는 API 테스트
- 정규장 전후 직접 입력 가능 여부에 대한 DST-aware 단위 테스트
- 자동 시가 없이 직접 입력한 값으로 주문 계산이 생성되는 API 테스트
- 직접 입력 해제 시 자동 시가 또는 대기 상태로 복귀하는 테스트
- 매수 비중 금액과 두 주문 수량 카드 표시를 보장하는 프론트엔드 테스트
- 기존 백엔드·프론트엔드 전체 테스트와 프로덕션 빌드
