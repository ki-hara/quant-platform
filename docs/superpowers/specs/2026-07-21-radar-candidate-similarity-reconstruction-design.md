# Radar Candidate Similarity Reconstruction Design

## 목적

radar0458의 추천 결과를 그대로 가져오는 것이 아니라, SOXL 추천에 사용되는 후보군 구성과 유사구간 선정 공식을 독립적으로 재현한다. 최종 산출물은 외부 사이트에 실시간으로 의존하지 않으며 날짜별 예외나 결과 하드코딩을 포함하지 않는다.

## 완료 기준

- 검증 기준일은 2012년 이후의 모든 미국 거래일이다.
- 공식 상위 3개 유사구간의 날짜가 모두 일치해야 한다.
- 공식 1위, 2위, 3위 순서가 모두 일치해야 한다.
- 화면에 표시되는 유사도가 반올림된 `0.01%p` 단위까지 모두 일치해야 한다.
- 하나의 고정된 후보 필터와 거리식을 전체 기간에 사용해야 한다.
- 날짜별 예외, 공식 결과 저장, 외부 사이트 실시간 조회로 일치를 만들면 완료로 인정하지 않는다.
- 위 조건을 충족하기 전에는 떨사오팔PRO의 공식 추천 기능으로 제품에 통합하지 않는다.

2012년 초 기준일의 지표 예열과 과거 후보 계산에는 2010~2011년 시장 데이터를 사용할 수 있다. 다만 공식 재현 정확도의 판정 구간은 2012년부터 시작한다.

## 접근 전략

구조 확인과 능동 역추론을 중심으로 진행하고, 전체 날짜 조회는 마지막 전수검사에만 사용한다.

1. 인증된 `POST /recommend` 응답과 공개된 페이지 자산에서 관측 가능한 구조를 확인한다.
2. 로컬 후보군과 공식 상위 3개 사이의 불일치를 유형별로 분류한다.
3. 여러 가설이 서로 다른 결과를 내는 날짜만 추가 질의하는 능동 표본 수집을 사용한다.
4. 후보 필터와 거리식을 고정한 뒤 미사용 기간에서 검증한다.
5. 최종 공식이 고정된 뒤에만 2012년 이후 모든 거래일을 전수검사한다.

전체 결과를 먼저 수집해 학습 모델로 외우는 방식은 사용하지 않는다. 사이트 추천을 그대로 읽는 방식도 공식 복원이 아니므로 제외한다.

## 관측 및 데이터 수집

### 응답 구조 조사

- `POST /recommend`의 요청 필드와 응답 HTML 구조를 기록한다.
- 숨은 입력값, 인라인 스크립트, 정적 자바스크립트, 소스맵과 차트 원시값을 확인한다.
- 별도 JSON 경로나 차트 데이터를 제외할 수 있는 경량 응답 방식이 있는지 우선 확인한다.
- 정상 로그인 계정에서 페이지가 제공하는 범위만 사용하고 접근 제한을 우회하지 않는다.

### 표준 표본 구조

각 기준일에 대해 다음 값을 구조화된 JSON으로 보관한다.

- 요청 기준일과 실제 분석 종료일
- 현재 구간의 정배열 상태
- 현재 구간의 MA20 기울기, MA20 이격도, RSI14, ROC12, 20일 변동성
- 공식 상위 3개 후보의 분석 구간과 성과 확인 구간
- 공식 후보의 순위와 표시 유사도
- 공식 후보의 다섯 지표, 전략별 수익률과 MDD
- 동일 시점에 로컬에서 계산한 전체 후보의 지표와 자격 조건
- 수집 시각과 응답 구조 식별값

원본 HTML은 파서 진단에 필요한 기간에만 임시 보관한다. 장기 연구 자료에는 파싱한 JSON과 응답 구조 해시만 남긴다. 로그인 쿠키, 계정 정보와 인증 헤더는 파일 또는 Git에 저장하지 않는다.

### 초기 수집 범위

- 연도와 시장 국면을 분산한 약 100개 기준일로 시작한다.
- 같은 날짜의 결과는 캐시하며 중복 요청하지 않는다.
- 요청 간격, 제한된 배치 크기와 지수 재시도를 적용한다.
- `302` 로그인 이동이나 인증 오류를 감지하면 즉시 수집을 중단한다.
- 사이트 결과가 동일 날짜에서 변경되는지 확인하기 위한 소수의 기준 날짜를 매 세션 다시 확인한다.

## 로컬 후보군 구성

미국 거래소 달력을 기준으로 각 거래일의 시장 지표를 계산한다. 지표 계산은 사이트의 시점 규칙에 맞춰 기준일 이전에 확정된 데이터만 사용한다.

우선 다음 조건을 확정 후보 필터로 적용하고 각각을 독립적으로 검증한다.

- 후보 지표 계산에 필요한 과거 데이터가 존재한다.
- 후보의 30일 성과 확인 구간이 기준일 전에 완전히 종료되었다.
- 현재 구간과 후보 구간의 정배열 상태가 같다.
- 후보 선택에 미래 데이터가 섞이지 않는다.

후보의 성과 확인 구간은 30일 달력일 기준인지 거래일 기준인지 실제 출력으로 다시 검증한다.

## 불일치 분류

공식 상위 3개와 로컬 최근접 후보의 차이를 다음 네 유형으로 분류한다.

1. **인접 날짜 대체:** 공식 후보 주변 날짜가 로컬 상위에 몰린다. 대표 구간 선정이나 중복 제거 규칙을 의심한다.
2. **원거리 후보 대체:** 전혀 다른 시기의 후보가 선택된다. 숨은 국면 필터나 추가 지표를 의심한다.
3. **순서 불일치:** 후보 집합은 같지만 순서가 다르다. 거리 가중치와 변환식을 조사한다.
4. **유사도 불일치:** 후보와 순서는 같지만 표시값이 다르다. 입력 정밀도, 반올림과 유사도 변환식을 조사한다.

각 불일치에는 어떤 필터 또는 거리식 가설이 설명 가능한지 태그를 붙인다. 설명되지 않는 불일치를 날짜별 예외로 처리하지 않는다.

## 후보군 필터 가설

다음 가설을 단순한 것부터 한 번에 하나씩 검증한다.

- 비슷한 30일 구간끼리 대표 날짜 하나만 남기는 중복 제거
- 후보 사이의 최소 날짜 간격
- 분석 구간 또는 성과 확인 구간의 중첩 제한
- RSI, 변동성, 이격도의 구간별 자격 조건
- MA120 상태와 이격도
- RSI 다이버전스 상태
- 기울기 부호와 급변 구간 분리
- 거래일 위치, 월말 또는 주간 경계 규칙

가설은 다른 연도에서도 동일하게 작동하고 미사용 검증 표본의 정확도를 높일 때만 채택한다. 공식 후보보다 로컬 거리상 가까운데 탈락한 후보를 일관되게 설명하지 못하는 가설은 폐기한다.

## 능동 질의

무작위 날짜를 추가하는 대신 현재 남아 있는 가설들이 서로 다른 상위 3개를 예측하는 기준일을 선택한다.

- 3위 후보와 첫 탈락 후보의 순위가 가설별로 바뀌는 날짜
- 연속된 거래일 사이에서 공식 후보가 교체될 것으로 예상되는 날짜
- 정배열 상태나 지표 구간 경계에 가까운 날짜
- 인접 구간 중복 제거 반경을 구분할 수 있는 날짜
- 숨은 변수 포함 여부에 따라 원거리 후보가 선택되는 날짜

각 질의는 가능한 많은 가설을 동시에 제거할 수 있어야 한다. 200개 이상의 능동 표본을 사용하고도 안정적인 후보 필터가 나오지 않으면 추가 수집을 자동 확대하지 않고 원인을 재검토한다.

## 거리식 및 표시 유사도

### 입력 정밀도

사이트 차트에 포함된 원시 종가와 이동평균을 로컬 시장 데이터와 비교한다. 화면에 표시된 반올림 지표가 아니라 내부 원시값을 사용했는지, 거리 계산 전에 지표를 반올림했는지를 각각 검증한다.

### 거리식 후보

- 가중 절댓값 거리
- 가중 제곱거리와 유클리드 거리
- 표준편차, 범위 또는 중앙값 기반 정규화
- 상대 오차와 절대 오차의 혼합
- 구간별 가중치 또는 임계값 초과 패널티
- 진단 목적의 마할라노비스 및 코사인 거리

복잡한 학습 모델은 누락 변수를 찾는 진단 도구로만 사용한다. 최종 공식은 고정된 계산식으로 표현할 수 있어야 한다.

### 순위 제약

각 표본은 다음 제약을 제공한다.

- 공식 1위의 유사도는 공식 2위보다 높다.
- 공식 2위의 유사도는 공식 3위보다 높다.
- 공식 3위는 모든 자격 있는 탈락 후보보다 높다.

표시 유사도가 `96.03%`이면 내부 유사도는 반올림 구간 `[96.025%, 96.035%)`로 취급한다. 순위 제약과 반올림 구간을 동시에 만족하는 거리식과 유사도 변환식을 찾는다.

비교할 변환식에는 `100 - distance`, 지수 감쇠와 역수 변환을 포함한다. 연속 가중치로 가능 범위를 찾은 뒤 정수 또는 단순 소수 가중치로 환원한다.

## 검증 분리

- **발견 구간:** 2012~2022년에서 시장 국면별로 추출한 표본
- **중간 검증:** 사전에 고정한 2023~2024년 표본
- **최종 미공개 검증:** 2025년 이후 거래일

최종 검증 전에 공식, 가중치와 필터를 고정한다. 최종 검증 결과를 본 뒤 공식을 수정하면 해당 기간은 더 이상 미공개 검증으로 취급하지 않는다.

검증은 다음 순서로 진행한다.

1. 시장 국면별 초기 표본
2. 가설을 구분하는 능동 표본
3. 사전에 고정한 중간 검증 표본
4. 최종 미공개 검증 기간
5. 2012년 이후 모든 미국 거래일 전수검사

각 단계에서 Top3 집합 정확도, 순서 정확도, 표시 유사도 정확도와 최초 불일치 유형을 기록한다.

## 전수검사 비용과 안전장치

현재 응답 크기가 약 6MB라면 전체 기간 조회에 20GB 이상의 전송량이 필요할 수 있다. 따라서 경량 응답 경로를 찾기 전에는 전수검사를 실행하지 않는다.

경량화가 불가능하면 다음 값을 먼저 산출해 사용자 승인을 받는다.

- 총 요청 수
- 예상 전송량
- 예상 실행 시간
- 요청 간격과 배치 크기
- 중단 및 재개 방식

모든 결과는 날짜별 캐시를 사용한다. 서버 오류, 속도 제한 또는 인증 만료 시 자동 중단하며 공격적인 병렬 요청은 사용하지 않는다.

## 중단 조건

- 200개 이상의 능동 표본에서도 안정적인 후보 필터가 발견되지 않는다.
- 숨은 변수를 계속 추가해야만 발견 표본 정확도가 개선된다.
- 검증 기간마다 공식이나 가중치를 다시 조정해야 한다.
- 동일한 날짜에 대한 공식 결과가 변경되어 알고리즘 버전을 고정할 수 없다.
- 경량 응답을 찾지 못했고 전수검사 비용이 승인되지 않았다.

중단 시에는 현재까지 확정된 규칙, 반증된 가설, 필요한 추가 관측을 보고한다. 추정 추천기를 공식 복원으로 포장하지 않는다.

## 산출물과 제품 통합 경계

조사 단계의 산출물은 다음과 같다.

- 인증 정보를 포함하지 않는 표준 표본 데이터
- 로컬 시장 지표 및 후보군 생성기
- 후보 필터 가설별 검증 보고서
- 거리식 및 유사도 반올림 검증 보고서
- 기간별 및 전수검사 결과

전수검사 완료 전에는 연구 코드와 제품 전략 엔진을 분리한다. 완료 기준을 모두 충족한 뒤 별도의 떨사오팔PRO 제품 설계와 구현 계획을 작성한다.
